# Basketweaver

EverQuest fistweaving/weaving timing overlay — Electron + TypeScript.

**Before starting work, read `SESSION_LOG.md`** (most recent entry at top) for a
succinct catch-up on recent changes, what's released vs. uncommitted, and open
threads. Verify its claims against `git status`/`git log` — the log can go stale.

When a session does meaningful work (a bug fix, a feature, a decision reached
after investigation), add a short entry to the top of `SESSION_LOG.md` before
the conversation ends or context gets cleared, so the next session can pick
up without the user having to re-explain everything.
